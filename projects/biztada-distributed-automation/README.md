### 🌐 Overview (English)
Biztada is an enterprise-grade multi-channel marketing automation platform, customer data platform (CDP), and real-time AI CRM. It coordinates **1,000+** concurrent worker nodes across cloud Linux servers and client desktop machines behind NAT without requiring port forwarding.
