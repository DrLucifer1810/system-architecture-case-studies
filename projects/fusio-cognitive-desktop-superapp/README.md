### 🌐 Overview (English)
Fusio is an enterprise-grade desktop SuperApp and decentralized cognitive node. It combines a high-performance **Rust (Tauri v2)** kernel with an adaptive **Python AI Brain** and a **React 18** presentation shell to provide autonomous multi-agent task execution, peer-to-peer skill sharing, native Telegram MTProto streaming, and deterministic macro compilation.

### 🇻🇳 Tổng quan (Tiếng Việt)
Fusio là một Desktop SuperApp cấp doanh nghiệp và là node nhận thức phi tập trung.
