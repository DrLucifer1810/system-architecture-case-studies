### 🌐 Overview (English)
The `local-server` project represents a complete, self-sovereign edge micro-datacenter architecture. It orchestrates the entire Tadagram/Biztada backend infrastructure—comprising **10 containerized microservices**, **4 polyglot data engines**, and an **edge reverse-proxy ingress**—running bare-metal on an energy-efficient on-premises node with 24/7 power and network resilience.

### 🇻🇳 Tổng quan (Tiếng Việt)
Dự án `local-server` đại diện cho một kiến trúc trung tâm dữ liệu thu nhỏ (Edge Micro-Datacenter) tự chủ hoàn toàn. Hệ thống điều phối toàn bộ cụm backend Tadagram/Biztada—bao gồm **10 microservices container hóa**, **4 động cơ cơ sở dữ liệu đa hình**, và **cổng đảo ngược Ingress tầng biên**—chạy bare-metal trên một máy tính Mini PC tiết kiệm điện với khả năng chịu lỗi mạng và nguồn điện 24/7.
